# 🌍 Earth And Moon Animation

An interactive frontend web project built using **HTML5** and **CSS3 Animations**, showcasing a revolving moon orbiting around planet Earth against a starry background.

## 🚀 Features
* **CSS Keyframes Animation:** Smooth, continuous orbital movement.
* **Responsive Styling:** Clean layout structure utilizing modern CSS properties.
* **Visual Assets:** High-quality background space imagery along with detailed textures for Earth and the Moon.

## 🛠️ Technologies Used
* **HTML5** (Structure)
* **CSS3** (Styling, Transitions, and @keyframes Animations)
